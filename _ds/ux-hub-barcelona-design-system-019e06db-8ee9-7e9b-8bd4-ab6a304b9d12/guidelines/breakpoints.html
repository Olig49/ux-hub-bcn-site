Breakpoints

Documentation only — these are literal @media values in site.css/mobile-tweaks.css/sponsors.html's inline styles, not custom properties (a media query can't read var()). Twelve widths, each tied to one or more specific layout changes.

WidthWhat changes
980pxEvent / card grids collapse to a single column.
900pxDonate section collapses to one column; sponsors.html's hero grid, pricing tiers, and sponsor grid collapse the same way.
880pxNav collapses to the burger menu.
820pxTwo-up layouts become one column (sponsors.html sponsor cards).
780pxFooter grid stacks; its vertical padding also tightens (96px 0 40px → 56px 0 32px) since the full desktop padding reads as needlessly tall once it's one column.
720pxPage wrap padding steps 32px → 20px; SectionHead collapses to one column; section numerals step to 72px; event-feature body padding tightens.
700pxHero collage hides entirely (display:none), replaced by the mobile image ticker — not a "keep one photo" fallback.
620pxMobile chrome adjustments — the nav bar's own CTA hides (the drawer's .drawer-cta becomes the only way to reach it), each partner-card's own internal layout goes two-column (numeral + heading inline).
600pxBackToTop shrinks to 44px.
540pxModal padding steps down (36px → 26px 22px); a modal option's tag pill hides.
520pxMailing-form label/fineprint padding tightens; the donate-form info tooltip repositions so it doesn't overflow a narrow card.
480pxSmallest-screen adjustments — nav logo shrinks, about-stats stays two columns, the mailing form's first/last-name row stacks to one column, footer logo shrinks.

Author new responsive rules against these same widths rather than introducing new ones — the list above is already the site's full set.
