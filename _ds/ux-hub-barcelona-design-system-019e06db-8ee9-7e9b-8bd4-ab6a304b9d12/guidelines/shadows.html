Foundations · Elevation

Shadows

Three soft, warm-tinted shadows — used to lift cards off the page instead of a hard drop shadow. A card takes a hairline border or a shadow, never both (see cards.html).

sm

0 1px 2px rgba(0,0,0,0.06)

Barely-there lift — the mailing-form input row.

md

0 6px 18px rgba(0,0,0,0.08)

Default card elevation — event feature, nav drawer.

lg

0 18px 40px rgba(15,55,58,0.12)

Highest layer — modal card, donate form. Tinted teal, not black.

All three shadows are tinted — sm/md use neutral black at low opacity, lg shifts to rgba(15,55,58,…) (teal-night) so the deepest shadow reads warm, not muddy grey.
