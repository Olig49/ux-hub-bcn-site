Accessibility notes

The corrections and rules the site carries over the raw brand guidelines. Treat every item here as a requirement, not a suggestion.

  • 1

    AA-corrected secondary text

    The brand's raw #777777 measures 4.48:1 on white and fails WCAG AA for normal text. --uxh-fg-2 ships as #6a6a6a instead, which passes. Always reach for the token — never hand-type #777.

  • 2

    Amber-on-dark substitution

    Yolk (#F3A632) on Teal Night measures only 3.7:1 and fails AA. Use --uxh-amber-on-dark (#F7C77E) for any accent-coloured text or icon on a dark surface — e.g. the tier-card price on the Teal Night pricing tier.

  • 3

    Teal text on warm surfaces

    Seaturtle body-size text on Ceramic or Soft Beige also fails at small sizes. Use --uxh-teal-night instead of --uxh-seaturtle whenever teal text sits on a warm background at body size or smaller.

  • 4

    44px tap targets, everywhere

    --uxh-tap-min: 44px is a floor, not a target size to round down from — every button, link-as-button, icon button and social link must clear it, including footer socials (34px desktop → 44px on touch) and team-card social links (28px → 44px).

  • 5

    16px minimum input font (iOS zoom)

    --uxh-input-font: 16px. Any text input set smaller than this triggers an automatic zoom on focus in iOS Safari, which is jarring and hard to undo one-handed. Applies to the mailing form and donate form inputs.

  • 6

    role="list" on styled <ul>

    VoiceOver and other screen readers stop announcing list semantics once list-style: none is applied. Any <ul> that needs its bullets removed (tier-card checklists, this very checklist) must carry role="list" to restore them.

  • 7

    Focus-visible states

    Every interactive element needs a visible keyboard-focus ring — :focus-visible { outline: 2px solid var(--uxh-seaturtle); outline-offset: 2px; } is the default. Tab to the button below to see it.

  • 8

    Reduced-motion handling

    All non-essential motion — the marquee strip, reveal-on-scroll, hover lifts, the arrow nudge — must stop or become instant under @media (prefers-reduced-motion: reduce). Reveal-on-scroll content is visible by default; the transition is added only when JS and motion are both available, so a reduced-motion visitor never loses content, only the animation.
