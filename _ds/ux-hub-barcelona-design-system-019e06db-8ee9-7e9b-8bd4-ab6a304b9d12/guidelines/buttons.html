Buttons

Four variants, one shared geometry: padding: 14px 26px, full pill, font: 600 15px/1, gap: 10px, min-height: 44px (the 44px tap-min floor). Real buttons below — hover and click them.

primary — rest: --site-accent bg (shown here as Yolk, the default) + dark fg text · hover: filter: brightness(0.95) · active: scale(0.98)

--site-accent is themable per page via html[data-accent="yolk|purple|lime|teal"] — this card shows the yolk default. Text stays dark (--uxh-fg) since every accent option is a light/mid tone.

ghost — rest: transparent, 1px solid rgba(0,0,0,0.16) · hover: rgba(42,153,160,0.08) bg, seaturtle border + text

dark — rest: --uxh-fg bg, white text · hover: --uxh-teal-night bg

onDark — rest: white bg, --uxh-fg text · hover: --uxh-ceramic bg — for use on Teal Night / Seaturtle panels

An optional trailing arrow icon nudges translateX(3px) on hover over --uxh-dur-move (200ms) — see motion.html. Every state above respects prefers-reduced-motion.
